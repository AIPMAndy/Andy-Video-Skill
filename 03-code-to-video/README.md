# 03 · Code-to-Video

Generate MP4 videos from source code (React / HTML / TypeScript).

| Skill | Tech Stack | Use Case |
|-------|-----------|----------|
| [react-video](./react-video/) | React / Playwright / ffmpeg | React components → MP4, knowledge video templates |
| [react-content-generator](./react-content-generator/) | React / Tailwind | Apple-style React knowledge pages (video source material) |
| [ai-video-producer](./ai-video-producer/) | Node.js / Playwright | End-to-end pipeline: GitHub Trending → topic → React PPT → auto-record MP4 |

## When to Use

You have **code or React components** and want to render them as video.
Typical use: educational explainers, product demos, knowledge visualization.
For full automation (source → publish-ready MP4), use `ai-video-producer`.
