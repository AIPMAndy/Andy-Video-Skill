## 通用设计原则

### 1. 页面数量
- **短视频（15-30 秒）**：3-4 页
- **中视频（30-60 秒）**：5-6 页
- **长视频（60-90 秒）**：7-8 页

### 2. 配音文本长度
- **每页 50-150 字**（对应 10-30 秒配音）
- **总长度 300-800 字**（对应 60-180 秒视频）

### 3. 视觉层次
- **开场页**：大标题 + 副标题 + 装饰元素
- **内容页**：标题 + 可视化 + 关键信息
- **结尾页**：总结 + CTA + 联系方式

### 4. 动画节奏
- **开场动画**：2-3 秒
- **主体展示**：10-20 秒
- **结尾过渡**：2-3 秒

### 5. 配色方案
- **科技感**：Indigo + Purple（#6366f1 + #a855f7）
- **商务感**：Blue + Cyan（#3b82f6 + #06b6d4）
- **活力感**：Emerald + Teal（#10b981 + #14b8a6）
- **温暖感**：Amber + Orange（#f59e0b + #f97316）

## 快速开始

### 1. 确定主题和目标
```
主题：[你的主题]
目标受众：[谁会看这个视频]
核心观点：[一句话总结]
```

### 2. 设计页面结构
```
第 1 页：开场（标题 + 核心观点）
第 2 页：痛点（问题可视化）
第 3 页：方案（解决方案展示）
第 4 页：案例（真实效果）
第 5 页：结尾（总结 + CTA）
```

### 3. 编写配音文本
- 每页 50-150 字
- 口语化、有节奏感
- 关键词加重语气

### 4. 生成项目
```bash
/react-content-generator "主题：[你的主题]" --pages=5
```

### 5. 生成视频
```bash
cd output
npm install
npm run dev

# 在另一个终端
/react-video-generator
```

## 常见问题

### Q: 如何调整动画速度？
A: 修改 `setTimeout` 的延迟时间和 CSS `transition-duration`。

### Q: 如何自定义配色？
A: 修改 `tailwind.config.js` 中的 `theme.extend.colors`。

### Q: 如何添加新的可视化组件？
A: 参考 `templates/visualizer-components.jsx`，遵循相同的状态管理模式。

### Q: 配音文本太长怎么办？
A: 拆分成多页，或者精简表达。每页最好不超过 150 字。

### Q: 如何优化视频质量？
A: 在 `react-video-generator` 中调整 `crf` 参数（15-18 为高清）。
