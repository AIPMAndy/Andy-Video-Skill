# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-01

### Added
- 🎉 Initial release
- CLI tool with `generate`, `render`, and `full` commands
- Scene template library:
  - Intro scene (question-based opening)
  - Concept scene (core explanation)
  - Conclusion scene (summary and takeaways)
- Color scheme presets:
  - 3Blue1Brown (default)
  - Cyberpunk
  - Nature
  - Minimal
- Quality presets: low/medium/high/production
- Complete Attention Mechanism example project
- Comprehensive documentation
- MIT License

### Features
- ⚡ 10x faster iteration vs After Effects
- 🎨 3Blue1Brown-style visual design
- 📦 No LaTeX dependency
- 🔧 Full CLI workflow automation
- 🎬 End-to-end video production pipeline

### Documentation
- README.md with quick start guide
- SKILL.md with complete workflow documentation
- CONTRIBUTING.md for contributors
- Example project with detailed README
- Troubleshooting guide

### Technical Details
- Python 3.8+ support
- Manim Community v0.18+ integration
- Node.js CLI interface
- Automated batch rendering
- Template-based script generation
