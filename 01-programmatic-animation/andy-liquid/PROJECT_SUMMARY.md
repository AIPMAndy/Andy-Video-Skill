### 2. GlassPanel
CSS glassmorphism with:
- 3 variants (subtle/medium/strong)
- 2 shapes (pill/rect)
- Optional glow effect
- Dark mode support

### 3. FluidButton
Interactive button with:
- Magnetic hover tracking
- Ripple click effect

- Icon support
