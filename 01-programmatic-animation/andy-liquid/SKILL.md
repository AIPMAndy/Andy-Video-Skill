# Andy Liquid

Three.js-based 3D liquid metal animation renderer. Produces professional-grade
visual effects for video: bloom post-processing, particle systems, dynamic camera
movements.

## Quick Start

```bash
cd andy-liquid
pnpm install
pnpm build
```

## Use Cases

- Brand launch videos
- Cinematic intros
- Generative art backgrounds

See `README.md` for full documentation.
