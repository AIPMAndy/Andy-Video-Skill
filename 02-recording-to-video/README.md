# 02 · Recording-to-Video

Turn long screen recordings into polished short-form videos.

| Skill | Tech Stack | Use Case |
|-------|-----------|----------|
| [andy-screencast-to-viral](./andy-screencast-to-viral/) | Python / FFmpeg | Long recordings → 30-90s viral short videos with AI editing, subtitles, and packaging |

## When to Use

You have raw screen recordings (2-10 minutes) and want to systematically
produce **100+ short-form videos** for Douyin / Bilibili / Xiaohongshu / YouTube Shorts.
Pipeline: analyze → intelligent edit → viral package → batch publish.
