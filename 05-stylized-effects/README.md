# 05 · Stylized Effects

Distinctive visual styles for explainer videos.

| Skill | Tech Stack | Use Case |
|-------|-----------|----------|
| [andy-paper-collage-explainer](./andy-paper-collage-explainer/) | Canvas / JS | Paper-collage hand-crafted explainer videos |

## When to Use

You need a **distinctive, non-generic visual style** — not corporate slide-deck
nor 3D cinematic. The paper collage style evokes craft, warmth, and approachability;
suitable for education, storytelling, and human-narrative topics.
